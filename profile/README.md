# SANGU Software Engineering

Course materials for **Software Engineering**, a 6 ECTS course for computer science students at **SANGU University**. The course combines engineering principles with Java programming: understanding requirements, designing software, implementing and testing it, collaborating through Git, and delivering and maintaining a working application.

**[Start here: the course website →](https://sangu-software-engineering.github.io)**

## Weekly topics

1. [Software engineering and programming foundations](https://sangu-software-engineering.github.io/#week-01)
2. [Version control and collaborative development](https://sangu-software-engineering.github.io/#week-02)
3. [Build tools and dependency management](https://sangu-software-engineering.github.io/#week-03)
4. [Requirements and workflow modelling with UML and Mermaid](https://sangu-software-engineering.github.io/#week-04)
5. [Development processes and project planning](https://sangu-software-engineering.github.io/#week-05)
6. [Modular programming and object-oriented design](https://sangu-software-engineering.github.io/#week-06)
7. [Behaviour, testing, and debugging](https://sangu-software-engineering.github.io/#week-07)
8. [Code quality, safe refactoring, and continuous integration](https://sangu-software-engineering.github.io/#week-08)
9. [Architecture and component interactions](https://sangu-software-engineering.github.io/#week-09)
10. [Secure and responsible software construction](https://sangu-software-engineering.github.io/#week-10)
11. [Runtime environments, Docker, and deployment modelling](https://sangu-software-engineering.github.io/#week-11)
12. [DevOps, delivery pipelines, and documentation publishing](https://sangu-software-engineering.github.io/#week-12)
13. [Logging, observability, maintenance, and integrated review](https://sangu-software-engineering.github.io/#week-13)

Lessons appear on the website as they are published. The website's [About page](https://sangu-software-engineering.github.io/about/) covers learning outcomes, prerequisites, what to install, and recommended reading.
